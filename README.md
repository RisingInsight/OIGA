## Abstract

Pairwise aerial cross-modal translation requires a dedicated model for each source-target direction, leading to quadratic growth in model count and deployment overhead.

To address this limitation, we propose **OIGA**, a single shared-latent flow matching framework for arbitrary-modality aerial image translation that supports all 12 translation directions among RGB, near-infrared (NIR), digital elevation models (DEMs), and SPOT satellite imagery, guided by free-form natural-language instructions. The generator is a flow-matching transformer that operates in a shared latent space learned by a single jointly trained KL-regularized variational autoencoder. A dynamic loss mask router supplements pixel-wise reconstruction with perceptual supervision for optical imagery and spatial gradient constraints for elevation maps. An open-instruction interface combines a LoRA-adapted CLIP encoder with an instruction-to-modality resolver, enabling users to express the desired translation in free-form natural language, with the resolved target modality serving as the internal physical anchor.

Extensive experiments across all 12 translation directions show that our unified model outperforms eight baselines in average FID while matching or exceeding the best average LPIPS, attaining the best generation realism with the largest margins on DEM-involved directions. It merges all directions into a single deployable weight set and maintains robustness to diverse free-form phrasing. By unifying these mappings, OIGA replaces twelve direction-specific checkpoints with one 722.6M-parameter model. This unified, instruction-interface paradigm establishes a scalable approach to multimodal image synthesis in UAV-based Earth observation and broader remote-sensing applications.

## Contributions

<div align="center">

![Qualitative comparison](figures/introduction.jpg)

*Qualitative comparison between traditional image translation methods and our method.*

</div>

The primary contributions are:

- We propose **OIGA**, a single shared-latent flow matching framework for open-instruction arbitrary-modality aerial image translation. One checkpoint covers all 12 directions; the family-level interface reuses the shared KL-VAE and backbone for additional image-like or geometric sensors without new full-size components.
- We design a **Dynamic Loss Mask Router on a shared KL-regularized VAE latent space**. It applies modality-appropriate supervision (photometric and perceptual losses for optical modalities and spatial-gradient constraints for DEM) while masking modality-inappropriate terms.
- We develop a **modality-calibrated flow-matching backbone with a lightweight open-instruction interface**. The backbone learns continuous velocity fields along linear interpolation paths with per-modality latent normalization and lightweight residual adapters; a frozen CLIP encoder with LoRA and an instruction-to-modality resolver map free-form user intent to the internal target anchor, while AdaLN-Zero only injects the resolved modality and timestep information.
- On FLAIR-HUB, OIGA achieves the best average FID and best average LPIPS among eight baselines across all 12 directions with a single 722.6M checkpoint; it runs at 1.16s per 512×512 sample, and requires no new full-size encoder, decoder, or backbone per modality.

This is a review-stage subset of the OIGA codebase. It provides:
